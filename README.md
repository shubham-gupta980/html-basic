# HTML Basics

A beginner-friendly repository containing HTML programs and practice files to learn the fundamentals of web development. This repository covers basic HTML concepts, semantic elements, forms, tables, multimedia, and simple webpage layouts.

## 📖 About

The purpose of this repository is to build a strong foundation in HTML by practicing essential concepts and creating simple web pages.

## ✨ Features

- Basic HTML structure
- Headings and paragraphs
- Text formatting
- Lists (Ordered & Unordered)
- Hyperlinks
- Images
- Tables
- Forms
- Semantic HTML elements
- Audio & Video embedding
- HTML entities
- Simple webpage layouts

## 🛠️ Technologies Used

- HTML5

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/shubham-gupta980/html-basic.git
```

2. Open the project folder:

```bash
cd html-basic
```

3. Open any `.html` file in your preferred web browser or use the **Live Server** extension in Visual Studio Code.
